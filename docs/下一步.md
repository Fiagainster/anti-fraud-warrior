# 下一步：把 demo 收到"看不出是 Doom 的 mod"

2026-11-22。三个自定义物件的占位图已经落地（`FZGT` / `FZEV` / `FZPF`），角色已经
全换，剩下最刺眼的是**声音**。这份文件定的是"接下来做什么、交什么、怎么算做完"。

## 0 结论先行

1. **顺序是 音效 → 音乐 → 剩下的道具**。不是音乐配乐优先：玩家耳朵里八成是音效，
   原版僵尸一叫就穿帮；而 Freedoom 的三首曲子本来就是完整可听的配乐，缺了不显得
   空，只是"不搭"。
2. **配音不做**。理由见 §5，一句话：UZDoom 没有对话系统，叙事已经靠 banner 与
   抉择菜单讲清楚了，加配音是负收益。
3. **每一步都要保证"仓库随时可运行"**。填一格是一格，任何时候 `chapter` 三章都该
   是 13/13，不允许出现"音频没到位所以玩不了"的状态。

## 1 现在还剩下的穿帮（按玩家感知强度排）

| # | 穿帮 | 现状 | 强度 |
|---|---|---|---|
| 1 | 音效全是 Freedoom 原版 | `game/sounds/` 空，全靠 IWAD | 最高：一听就是老 Doom |
| 2 | 音乐是 Freedoom 别名 | `MAPINFO` 写着 `Music = "$MUSIC_E1M1"` 这类 IWAD 别名 | 中：能用但不搭 |
| 3 | 弹药 / 护甲 / 血包还借 Freedoom 图 | `CLIP` `SHEL` `ARM1` `MEDI` `STIM` | 低：玩家不会觉得"缺东西" |
| 4 | 简报物件是隐形的 | `FZBR` 还没画，只有 banner 文字 | 低：本来就是纯触发器 |
| 5 | 受击没有白闪、死亡没有血迹 | 状态里只有 `A_Pain` 之类 | 低：手感问题，最后统一 |

## 2 P1：音效（下一步就做这个）

### 2.1 为什么它排第一

`game/sounds/` 是空的，所以现在整局的听觉完全由 `freedoom1.wad` 提供。这意味着
玩家开枪、开门、捡东西、被咬，听到的全是 1994 年那套音色。视觉已经自研了，
听觉还停在原地——这是目前"不像自己做的"的最大单点。

### 2.2 交什么

统一放 `game/sounds/`，格式优先 **OGG**（体积小、无版权合成器问题），其次 WAV。
文件名 ≤ 8 字符、全大写、ASCII（引擎会对超长名静默截断，这条在贴图那边已经踩过）。

**第一批只要 10 个**，全是"每局必然听到很多次"的：

| 逻辑名 | 触发时机 | 建议长度 | 备注 |
|---|---|---|---|
| `FZ_PICK_EV` | 捡到证据箱 | 0.3–0.5s | 核心正反馈，最值得花时间做 |
| `FZ_TERM_ON` | 走近终端弹抉择 | 0.5–1.0s | 要"电子提示"，不是"机械咔哒" |
| `FZ_GATE_OP` | 审判门解锁开启 | 1.0–1.5s | 要有"闸门放行"的重量 |
| `FZ_SWITCH` | 出口开关 | 0.4s | 干脆的"确认" |
| `FZ_PISTOL` | 警示枪开火 | 0.3s | 塑料感 + 电子蜂鸣，别做成真枪 |
| `FZ_SHOTGUN` | 封条枪开火 | 0.4s | 比手枪闷、低一档 |
| `FZ_MOB_HURT` | 怪物受击（通用） | 0.2s | 6 种共用，靠音高区分不如靠后续加 |
| `FZ_MOB_DIE` | 怪物死亡（通用） | 0.5s | 同上 |
| `FZ_BOSS_DOWN` | 会长倒下 | 1.5s | 一章只有一次，可以夸张 |
| `FZ_MENU_OK` | 抉择菜单确认 | 0.15s | 短促，别盖住文案 |

第二批（等第一批进引擎听过再补）：6 种怪物各自嚎叫 / 玩家受击 / 玩家死亡 /
弹药拾取 / 护甲拾取 / 血包拾取 / 普通门开关 / 红锁门拒绝。

### 2.3 怎么接线（我来做，你不用管代码）

三步，第一步现在是缺的，动手时我补：

1. **建 `game/sndinfo.txt`**，把逻辑名绑到音效文件。同时要在 `tools/build.py`
   的文件清单里登记 `sndinfo.txt`，否则它不会进 pk3 根目录、引擎读不到。
2. **给 6 个 `FZ*` 类补声音属性**。现在的 `FZShill : ZombieMan` 只覆盖了 `States`
   里的精灵帧，声音还是继承原版。ZScript 的 actor 有 `SeeSound` / `PainSound` /
   `DeathSound` / `ActiveSound` 这几个字段（引擎侧是 `actor->SeeSound`），在
   `Default` 块里指过去即可，AI 一行不用改。
3. **我们自己的物件用 `A_StartSound`**：证据箱、终端、审判门、出口开关都在
   `fz_defs.zs` / `fz_gates.zs` 里，各加一行。

### 2.4 怎么算做完

- `python tools/fz_ctl.py chapter FZ01` 仍是 **13/13**（换声音不能碰坏流程）；
- 进游戏走一章，闭着眼睛听：**听见任何一个"这不是原版 Doom"以外的声音，算通过**；
  反过来只要还能听出原版僵尸嚎叫，就还有没盖住的地方；
- `build.py` 打包后 pk3 根目录里有 `sndinfo.txt`，`game/sounds/` 的文件在包里。

## 3 P2：音乐

### 3.1 交什么

| 用途 | 章 | 基调 | BPM | 长度要求 |
|---|---|---|---|---|
| 关卡 | FZ01 刷单深渊 | 冷、机械、重复 | 128 | 主体 ≥60 秒可无缝循环 |
| 关卡 | FZ02 装备黑市 | 市集、油滑、试探 | 92 | 同上 |
| 关卡 | FZ03 警服幻影 | 权威、压迫、伪善 | 110 | 同上 |
| 菜单 | 全局 | 悬置、待命 | 70 | ≥45 秒，能长时间循环 |

格式与参数（`docs/贴图与音乐方案.md` §2.4 / §5 已定）：**OGG Vorbis，44.1kHz
立体声，质量 q4**，统一到 **-16 LUFS / 真峰值 -1.5 dB**，否则音乐会把枪声压住。

结构写「8 小节前奏（只播一次）+ 主体（循环）」，用 Vorbis 注释标循环点：

```
LOOP_START = 0:00.000
LOOP_END   = 1:32.500
```

没有循环标签就退化成整曲循环，也能用，只是前奏会反复听到。

### 3.2 怎么接线

文件放 `game/music/D_FZ01.ogg`，`game/mapinfo/MAPINFO` 改一行：

```
map FZ01 "第一章：刷单深渊" { Next = "FZ02" Sky1 = "SKY1" Music = "D_FZ01" }
```

`$MUSIC_E1M1` 那种写法是 IWAD 别名，换成自己的名字就不再依赖 Freedoom。
`tools/build.py` 已经把 `music/` 打进包了，目录不存在就跳过，所以随时可以只放一首。

### 3.3 怎么算做完

一首一首替换，每换一首跑一次 `chapter` 对应章。判断标准只有一个：**循环接缝听不
出来**。听不出来就过，别的都是审美问题。

## 4 P3：剩下的美术（不阻塞）

| 物件 | 精灵名 | 画布 | 现在的替代品 |
|---|---|---|---|
| 弹夹 | `FZCL` | 8×14 | `CLIP` |
| 霰弹 | `FZSH` | 8×14 | `SHEL` |
| 防骗盾（甲） | `FZAR` | 24×24 | `ARM1` |
| 警惕值（血） | `FZMD` | 20×20 | `MEDI` / `STIM` |
| 简报 | `FZBR` | 32×40 | 无（本来就是隐形触发器） |

这五个换掉之后，"看得见的东西"就全是自研了。但它们**不影响试玩感受**，玩家不会
因为血包还是原版就觉得 demo 不完整，所以排在音频之后。

## 5 不做：配音

1. UZDoom 没有对话系统。要配音得新做 actor + 字幕 + 触发时序，工作量比三首曲子大，
   做不好比不做更差（半句台词突然静音、音量跟音乐打架）。
2. 叙事已经能读懂了：开场简报 banner、抉择菜单、答对/答错的识破文案，全是文字。
   玩家不需要"听见"谁说话。
3. 合规上只能当预演。`docs/协作/素材授权与AI合规.md` 写明 AI 可用于"配音预演"，
   不能直接当成品；真人录音又得先有剧本和录音条件；真实警员声音更不能仿。
4. 真要做配音，那是**反诈宣传片**版本的事，不是**试玩 demo** 版本的事。

## 6 排期建议

按"一次改动就要能跑一遍全流程"为单位，不按小时估：

| 轮次 | 做什么 | 出关条件 |
|---|---|---|
| R1 | 三个物件换正式美术 + 音效第一批 10 个 | `chapter` 三章 13/13，听觉不再穿帮 |
| R2 | 音乐 3 首 + 菜单曲 | 循环听不出接缝 |
| R3 | 音效第二批 + 剩下 5 个道具图 | `full` 三章跑通 |
| R4 | 受击白闪 / 血迹 / 屏幕震动 | 只能靠手感判断，我自己玩一遍 |

## 7 需要你拍板

1. **音效谁出**：你录 / 找 CC0 素材库 / AI 生成（AI 音效多数服务条款允许商用，
   但要登记到 `assets_src/CREDITS.md`）。
2. **音乐谁写**：你作曲 / CC0 / AI。三首里只要有一首不行，整局的"氛围"就立不住，
   这项最吃个人审美，建议你自己定调。
3. **要不要装 ffmpeg**：装了能自动做 OGG 转码 + 循环标签 + 响度归一
   （`winget install Gyan.FFmpeg`，单文件 exe）。不装就手调音量、整曲循环。
4. **`full` 那个 19/22 要不要先治**：它不是音频问题，但决定你每次改完能不能一键
   确认三章还通。要么先花一轮把机器人的"让位"逻辑修好，要么先忍着用 `chapter`
   逐章跑。

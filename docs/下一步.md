## 3 已完成：五首配乐（2026-11-23）

### 3.1 交付了什么

5 首，曲目名与章节标题一致（设计见 [音频设计.md](音频设计.md) §4，落地记录见 §4.1）：

| 曲目 | 用途 | BPM | 长度 | 循环点 |
|---|---|---|---|---|
| `title` | 标题 / 选章 | 70 | 27.4s | 整曲循环 |
| `ch1` | 第一章 刷单深渊 | 128 | 75.0s | 15.0s 起 |
| `ch2` | 第二章 装备黑市 | 92 | 104.4s | 20.9s 起 |
| `ch3` | 第三章 警服幻影 | 110 | 104.7s | 34.9s 起 |
| `boss` | 主席战 | 140 | 41.1s | 13.7s 起（暂无宿主地图） |

格式：**OGG Vorbis，44.1kHz 立体声，q5，−16 LUFS，真峰值 ≤ −1.5 dBFS**，全部按实测达标。

### 3.2 怎么接的线

文件在 `game/music/*.ogg`，`game/mapinfo/MAPINFO`：

```
gameinfo { ... titleMusic = "music/title.ogg" }
map FZ01 "第一章：刷单深渊" { Next = "FZ02" Sky1 = "SKY1" Music = "music/ch1.ogg" }
```

`Music =` 的完整路径能直接命中 pk3 内的文件（`S_ChangeMusic → FindMusic → CheckNumForFullName`），
不再依赖 `$MUSIC_E1M1` 这类 IWAD 别名。`tools/build.py` 会把 `music/` 原样打进包。
循环点写在 OGG 的 `LOOP_START`/`LOOP_END` 注释里，单位是采样。

### 3.3 怎么验收的

- `python tools\fz_ctl.py check`：脚本 / MAPINFO 编译通过；
- `python tools\fz_ctl.py static`：192/192；
- `python tools\fz_ctl.py chapter FZ01`：13/13（注意它带 `-nosound`，验不了音乐）；
- **音乐必须单独带声音验**：手动起一次引擎、`+map FZ01`，日志里不应出现
  `Music "…" not found`。判据是"故意写错路径会报错、真路径不报错"，见开发日志。
- 听感：接缝（每首循环点前后各 8 秒）在制作工作区 `D:\Project\音乐美术生成\music\out\loopseam\`。

### 5.1 手持武器：骨架不是一张 82×92

原版那 9 帧**每帧画布都不一样**，因为后坐/枪口焰把包围盒撑大了：

| 帧 | PISG（手枪） | SHTG（霰弹） |
|---|---|---|
| A | 82×92 | 67×62 |
| B | 82×96 | 88×128 |
| C | 84×100 | 93×143 |
| D | 84×106 | 108×129 |
| E | 86×120 | — |

每帧的 `left/top` 也随之不同（`PISGA0` 是 −125/−97）。自己画的时候**不必照抄**：
选一张固定画布（比如手枪 96×120、霰弹 128×160），所有帧都在同一张画布里，
只挪里面的枪身/手，`tools/fix_offsets.py` 会按 `(w/2−160, h−148)` 给每帧算出同一个
锚点——这样连发时枪不会抖，比原版那套更好维护。

`tools/weapon_ref.py` 会把原版每帧按引擎的真实屏幕位置摆进 320×200 画面，
并标出网格和锚点，照着描就行。

## 3 P1：音乐

### 3.1 交什么

5 首，曲目名与章节标题一致（详见 [音频设计.md](音频设计.md) §4）：

| 曲目 | 用途 | BPM | 长度 |
|---|---|---|---|
| `title` | 标题 / 选章 | 70 | 20–30s 循环 |
| `ch1` | 第一章 刷单深渊 | 128 | 8 小节前奏 + 32 小节主体循环 |
| `ch2` | 第二章 装备黑市 | 92 | 两段式，主体循环 |
| `ch3` | 第三章 警服幻影 | 110 | 慢起，主体循环 |
| `boss` | 主席战 | 140 | 8 小节 loop |

格式：**OGG Vorbis，44.1kHz 立体声，q5，−16 LUFS，真峰值 ≤ −1.5 dBFS**。

### 3.2 怎么接线

文件放 `game/music/ch1.ogg` 等，`game/mapinfo/MAPINFO` 改一行：

```
map FZ01 "第一章：刷单深渊" { Next = "FZ02" Sky1 = "SKY1" Music = "music/ch1.ogg" }
```

`$MUSIC_E1M1` 是 IWAD 别名，换成自己的文件后就不再依赖 Freedoom。
`tools/build.py` 已经把 `music/` 打进包，目录不存在就跳过，所以可以一首一首换。

### 3.3 怎么算做完

一首一首替换，每换一首跑一次对应章的 `chapter`。判断标准只有一个：**循环接缝听不出来**。

## 4 P2：配音

### 4.1 做什么

不是对话系统，是 6 个敌人的三种短句：

| 槽位 | 触发 | 长度 |
|---|---|---|
| `SeeSound` | 发现玩家 | 0.6–1.2s |
| `PainSound` | 受伤 | 0.4–0.8s |
| `DeathSound` | 死亡 | 0.6–1.5s |

6 个角色：刷单业务员 / 跑分仔 / 割韭菜 / 跑分中介 / 假警察 / 主席。
声线设定、18 条台词、录音规范见 [音频设计.md](音频设计.md) §5。

### 4.2 怎么接线

1. 按 `FZ<角色>_<槽位>.wav` 命名放进 `game/sounds/voice/`；
2. `SNDINFO` 登记 `fz/voice/shill_sight` 这类逻辑名；
3. actor 的 `Default` 块里挂三个槽位，AI 与状态机一行不用改。

### 4.3 怎么算做完

先只录刷单业务员的 3 条，接进 FZ01 实机走一段；声线、响度、后期都确认后再铺开到 6 个角色。
暂时找不到人就用中文 TTS 生成同名占位，真人到位直接替换文件。

## 6 排期建议

按"一次改动就要能跑一遍全流程"为单位，不按小时估：

| 轮次 | 做什么 | 出关条件 |
|---|---|---|
| R1 | 音乐 1 首（先做 `ch1` 试听） | 循环接缝听不出，`chapter` 13/13 |
| R2 | 音乐其余 4 首 | 同上 |
| R3 | 配音：刷单业务员试音 → 6 角色全量 | 实机听感一致，无爆音 |
| R4 | 剩下 5 个道具图 + `full` 机器人修复 | `full` 三章跑通 |
| R5 | 受击白闪 / 血迹 / 屏幕震动 | 只能靠手感判断 |

## 7 需要你拍板

1. **音乐谁写**：你作曲 / CC0 素材 / AI 生成。三首里只要有一首不行，整局氛围就立不住。
2. **配音谁录**：你找人 / 中文 TTS 占位。真人优先，先录一个人试水。
3. **要不要装 ffmpeg**：装了能自动 OGG 转码 + 循环标签 + 响度归一（`winget install Gyan.FFmpeg`）。
4. **`full` 那个 19/22 要不要先治**：它不是音频问题，但决定你每次改完能不能一键确认三章还通。

# 贴图与音乐：调研与方案

调研时间 2026-11-21。结论先行，依据在后。引擎是 UZDoom 5.0.3（GZDoom 系分支），
所有"引擎支持什么"的说法都按 ZDoom/UZDoom 的文档与实测来，不凭印象。

## 0 三句话结论

1. **贴图不用量调色板**：PNG 真彩直接可用，名字 ≤ 8 字符、放对目录就是一张贴图。
   唯一硬约束是尺寸——flat 必须方形且是 2 的幂（软渲染会花屏），墙只要边长是 2 的幂。
2. **音乐走 OGG，不走 MIDI**：MIDI 的听感取决于玩家机器的合成器（OPL / FluidSynth
   差别巨大），OGG 是确定的。OGG 还能写 `LOOP_START/LOOP_END` 标签做无缝循环。
3. **缺口很小**：三章地图今天只用到 **11 个贴图名**，加上门/开关/天空也就 15 个槽位；
   音乐 3 首（+菜单/Boss 可选）。这是一个人一周内能填满的量，不需要素材库。

## 2 引擎侧硬约束（已核实）

### 2.1 目录语义

| 目录 | 引擎怎么读 |
|---|---|
| `textures/` | 墙贴图命名空间，PNG 直接按文件名（不含扩展名）成为贴图名 |
| `flats/` | 地面/天花命名空间，规则同上 |
| `patches/` | **只给 TEXTURES 用**的素材，不参与直接查找 |
| `music/` | 普通文件，被 `MAPINFO` 的 `Music=` 按名字引用 |

名字规则：≤ 8 字符、ASCII、大小写不敏感。超长的图片名会被截断成前 8 个字符，
这是"贴图明明放进去了却显示成别的"最常见的来源。

### 2.2 尺寸

| 类型 | 要求 | 越界的后果 |
|---|---|---|
| flat | **方形**，边长 64 / 128 / 256 | 软渲染器花屏（硬件渲染器能救，但不能赌） |
| 墙 | 边长是 2 的幂（128×128、256×128 都行） | 软渲染器异常 |
| 天空 | 256×128（横向平铺） | 拉伸、错位 |

比 2 的幂更奇怪的尺寸不是不能救：`TEXTURES` 里用 `XScale/YScale` 声明缩放即可，
但那属于"特例"，不作为常规做法。

### 2.3 TEXTURES 是什么

它不是必需的。图片放对目录、名字合格，就已经是一张贴图。`TEXTURES` 只在三种情况
下需要：

- 要缩放（1024×1024 的原图当 128×128 用）；
- 要合成（在墙面上贴一张海报/标语）；
- 要跨命名空间（把同一张图同时注册成 `Texture` 和 `Flat`）。

语法（`Flat` / `Texture` 是两种命名空间）：

```
Texture FZPOSTER, 128, 128
{
    Patch "textures/FZW3WALL.png", 0, 0
    Patch "patches/poster_anti_fraud.png", 16, 24
}
```

`Patch` 后面的路径可以是完整路径（名字超 8 字符必须写全路径，这也是 `patches/`
存在的意义：不占贴图名、不被直接查找）。

### 2.4 音乐格式

| 类别 | 格式 | 备注 |
|---|---|---|
| MIDI 系 | MID/MIDI、MUS、HMI、HMP、XMI | 由玩家的合成器发声，听感不可控 |
| 流媒体 | **OGG**、FLAC、MP3、OPUS、WAV | OGG/FLAC 支持循环标签 |
| 模块 | MOD / XM / IT / S3M … | 需要自带采样，体积大 |
| 芯片模拟 | SPC / NSF / GBS / VGM … | 复古味，但不适合本项目基调 |

关卡音乐**默认循环**，不需要额外设置。精确循环点靠 Vorbis 注释：

```
LOOP_START = 0:00.000        （或写采样数：0）
LOOP_END   = 1:32.500        （或写采样数）
```

MP3 不支持自定义标签，所以走 MP3 就只能整曲从头循环（前奏会被反复听到）。

## 3 已经落地的管线（本次代码改动）

这部分不是提案，是已经在仓库里跑通的东西。

| 改动 | 文件 | 效果 |
|---|---|---|
| 打包清单加 `textures/flats/patches/music` | `tools/build.py` | 目录存在就进 pk3，不存在就跳过 |
| 校验改成「IWAD **或** 自带贴图」 | `tools/gen_maps.py: own_tex_names()` | 自绘贴图能通过，但打错名字依然报错 |
| 新增贴图工序 | `tools/gen_textures.py` | `check` 体检 + `fit` 缩放落位 |
| 静态测试同步 | `tools/test_game_logic.py` | 贴图名断言认得自带贴图 |

`gen_textures.py` 做四件事：

1. **命名体检**：长度、ASCII、textures/flats 之间重名、flat 是否方形 2 的幂；
2. **接缝体检**：比较左右列/上下行的平均通道差，>12 标 `seam?`（提示不是判决）；
3. **缩放落位**：`art/<槽位>.png`（任意尺寸）→ `game/textures/FZW3WALL.png`（128×128）；
4. **预览**：`_staging/texsheet.png` 出联系表，一眼看完全部贴图和接缝分数。

18 个槽位已固定（3 章 × 主墙/次墙/地面/天花 + 门/门轨/开关 + 3 天空），
键名形如 `fz03_wall_main`、`sky_fz02`，跑 `python tools\gen_textures.py fit` 会
打印还空着哪几个。

实测记录：两张占位贴图（`FZW3WALL` 128×128 墙、`FZF3FLR` 128×128 地面）已接进
第三章，`chapter FZ03` 13/13 通过，截图确认渲染正常。

顺带一提，这套体检第一次跑就把我自己起的名字 `FZF3FLOOR` 判了死刑——9 个字符。
名字长度这条不是形式主义，超长会被引擎静默截断。

## 4 贴图怎么设计

分三层，按"必要 → 有味道 → 锦上添花"排。

**L1 基础三件套（12 张，必做）**
每章一套「主墙 / 次墙 / 地面 / 天花」。次墙承担结构对比（柱、台基、门框），
所以要和主墙有明显明度差（≥ 25%）或材质差（砖 vs 金属 vs 瓷砖）。

**L2 语义件（3 张 + 可选合成）**
审判门、门轨、出口开关。这三张是玩家真正会盯着的交互物件，值得单独画。
再加一层「海报」：用 `TEXTURES` 把一张 32×48 的标语图合成到主墙上，
成本极低，但它是本项目唯一能把"反诈"讲在墙面上的地方。

**L3 天空（3 张）**
`Sky1 = "FZSKY1"`。256×128 横向平铺，三章三张（夜城天际线 / 阴天厂房 / 雨夜霓虹）。
一张天空对氛围的提升比五张墙贴图都大。

**风格规范**（按现在的观感定的，不是通用教条）

| 项 | 规定 | 理由 |
|---|---|---|
| 尺寸 | 墙 128×128，地面 128×128，天空 256×128 | 与现有房间尺度匹配（房间 128~960 宽） |
| 像素密度 | 1 像素 = 1 世界单位 | 128 单位的走廊正好贴一块砖，不出现半块 |
| 明度 | 主墙中灰（60~90），天花更暗（40~60），地面偏亮 | 现在的黑天花板教训：场景暗≠氛围好 |
| 细节频率 | 不要高频噪点 | 128 尺寸下高频会糊成一团灰 |
| 重复特征 | 谨慎加"踢脚线/腰线"这类横向带状特征 | 128 高的墙上每条都出现一遍，会变成条纹 |

## 5 音乐怎么设计

**曲目表**

| 用途 | 章 | 基调 | BPM | 编排重点 |
|---|---|---|---|---|
| 关卡 | FZ01 刷单深渊 | 冷、机械、重复 | 128 | 低音固定音型 + 金属敲击，像流水线 |
| 关卡 | FZ02 装备黑市 | 市集、油滑、试探 | 92 | 手鼓/铃 + 低音贝斯，中段留空 |
| 关卡 | FZ03 警服幻影 | 权威、压迫、伪善 | 110 | 军鼓进行 + 铜管动机 + 远处警笛 |
| 菜单 | 全局 | 悬置、待命 | 70 | 单音铺底 + 稀疏脉冲，能长时间循环 |
| Boss | 可选 | 三章共用变奏 | 140 | 章节曲的加速重编 |

**格式决策**：OGG Vorbis，44.1kHz 立体声，质量 q4（约 1.2~1.6 MB/首）。
理由见 2.4：MIDI 的听感由玩家合成器决定，而"警察局的味道"一半在音色上。

**循环**：成曲结构写成「8 小节前奏（只播一次）+ 32 小节主体（循环）」，用
`LOOP_START/LOOP_END` 标出主体区间。没有 ffmpeg 就退化成整曲循环，也能用。

**音量**：统一到 `-16 LUFS`、真峰值 `-1.5 dB`。OGG 天生比 MIDI 合成器响得多，
不归一化就会出现"音乐盖住枪声"。

**接线**：文件放 `game/music/D_FZ01.ogg`，`MAPINFO` 里 `Music = "D_FZ01"` 一行。
`$MUSIC_E1M1` 那种写法是 IWAD 别名，换成自己的名字就不再依赖 Freedoom。

**版权**：如果不用原创，CC0 最省事；CC-BY 必须在仓库里放 `CREDITS.md` 列明
作者与来源链接。AI 生成的曲子要看服务条款（多数免费档不允许商用）。

## 7 需要你拍板

1. **贴图谁画**：你手绘 / 我给你 AI 草稿你改 / 直接用 AI 生成不修。
2. **音乐谁写**：你作曲（我提供模板与循环标记脚本）/ 找 CC0 素材 / AI 生成。
3. **要不要装 ffmpeg**：装了就自动 OGG 转码 + 循环标签 + 响度归一；不装就整曲循环、
   音量靠手调。单文件静态 exe，`winget install Gyan.FFmpeg` 即可。
4. **要不要"叙事贴图"**：海报、标语、假公章这类贴在墙上的东西，工作量小、辨识度高。

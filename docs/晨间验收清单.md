# 验收清单

两种验法，任选其一。

## A. 交付包（推荐，模拟真实玩家）

1. 解压 `dist/fanzha-demo-v0.1.zip` 到任意目录（路径不要含奇怪字符）。
2. 双击 `run.bat`。窗口 1280×720，标题画面按回车 → **难度选择**（只有一个章节，引擎会自动跳过章节菜单）→ 开始。
3. 底部应看到中文 HUD：
   `反诈战士 / 警惕值 100 / 防骗盾 0 / 证据 0/3 / 进度 0/3 / 调查刷单群 / 96110`。
4. 停留几秒，屏幕中下方依次弹出三条简报字幕（简报/提示/提示）。
5. 沿走廊向东，走进发光终端 → 自动弹出抉择菜单：
   - 第一项是正确项（绿色高亮）：`拒绝垫付，举报该群`
   - 回车确认 → 防骗盾 +10、证据 +1、关卡进度 1/3
   - 若选第二项（错误）→ 警惕值 -25 并引来妖魔
6. 竞技场北墙三个小房间各有一个证据箱，走近自动拾取，集齐 3 件。
7. 走到红锁门（审判门）前，HUD 右下应显示红字「红卡」；按 E 门升起并保持敞开，可直接走进去。
8. Boss 房击杀群主；走到出口小间（绿色开关墙前）自动结算本章。
9. 标准结算页显示击杀/物品/时间，**按回车进入第二章**，重复同结构。
10. 主菜单：**按住 ESC 约 2 秒**（短按会被按键重复机制吞掉）。
    菜单里的中文字体、选项切换应正常。

## B. 仓库内自动化（改代码后必跑）

```powershell
python tools\fz_ctl.py check    # 编译预检：脚本错误直接失败，不弹窗
python tools\fz_ctl.py tour     # 第一章全程回归（预期 9/9 通过）
```

`tour` 会在 `_staging\fztest\bot_shots\` 留截图：`menu_*_before/after.png`
（抉择菜单作答前后）、`99_final.png`（终点 HUD）等。

注意：自动化会短暂接管键鼠，但只操作**它自己启动的 uzdoom 进程**
（按 PID 锁定）；你正在玩的游戏窗口不会被误操作。为稳妥，跑测试时
请先关掉自己的游戏窗口。

## 已知瑕疵（不影响游玩）

- 敌人精灵已全部自制；玩家手持武器按设计使用 IWAD 原版帧，地面拾取是自制图
- 音乐仍是 Freedoom 原声，敌人语音仍是原版怪叫（见 `docs/下一步.md`）
- 抉择菜单仅键盘（鼠标点击待做）
- 若启动随机崩溃：删除 `%LOCALAPPDATA%\doom\uzdoom\vulkanpipelinecache`
  再启动（强杀进程会弄脏 Vulkan 缓存）
- 全屏下若画面发虚：用窗口模式（run.bat 默认），根因是 DPI 拉伸
- 标题页停留数秒会播放 Freedoom 自带的旧格式 demo（作用于当前起始地图），
  按任意键回到标题；后续用 TITLEMAP 或自录 DEMO 替换

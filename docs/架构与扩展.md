# 架构与扩展指南

面向接手的程序/关卡同学。目标是让你在 1 小时内知道"改一个东西要动哪些文件"。

## 一次抉择的完整链路

```
touch FZGateTerminal
   → TryPickup: 若 done || mCool>0 直接返回；否则 GiveInventory FZGateLock(GateId)
   → FZStatusBar.Draw (ui) 发现 lock → FZChoiceMenu.ActivateMenu
   → Enter → Commit → SendNetworkEvent('FZGateChoice', gid, choice) → Close
   → FZPlayEvents.NetworkProcess (play)
        TakeInventory lock + GiveInventory cool
        correct → GateStage + ArmorBonus + MsgRight + FZEvidenceChain.Grant() + 终端 done
        wrong   → DamageMobj(FZFraud) + Ambush + MsgWrong
        两个分支都给该终端 StartCool(140 tic)
```

要点：`done` 让答对的终端退休，`mCool` 防止玩家站在终端里被反复喂菜单；
两者都在 `WorldLoaded` 换章时随 Actor 一起重建，所以只在本章内有效。

## 证据链与审判门

```
抉择答对 1 次  → FZStage<N> + FZEvidenceChain.Grant()
证据箱（3 个） → FZEvidencePickup → 直接给 1 件 FZEvidence
红卡条件 = (证据 >= 3) AND (FZStage1 在身) AND (FZStage2 在身)
          3 件齐但题没答对 → 只推 905 提示，不发红卡
红卡 → 走到审判门（D1 红门 special 33）按 E → 进 Boss 房
BaronOfHell 死亡 → WorldThingDied → Spawn FZMasterProof → FZStage3 +1 → 出口结案
```

**为什么要两个条件**：三个证据箱自己就能凑满 3 件，若只看证据数，"两题全答错、
只捡箱子"照样能开门，反诈题白答。加上 Stage 条件后，答题才有真正的否决权：
证据箱负责"凑数"，答题负责"能不能结案"。

**为什么不卡关**：答错时 `FZGateTerminal` 不置 `done`（只有答对、或已持有该题
Stage 令牌才置），冷却 4 秒后走开再靠近就会重新弹菜单——代价是掉警惕值 +
伏击。HUD 的 905 横幅会直接告诉玩家"证据齐了但还有题没答对，回去重答"。
`fz_ctl retry` 场景就是把这条路径跑出来：第一题故意答错 → 回终端重答 →
ev=3 red=1 → 审判门开。

## 换章状态清零（必须保留）

玩家跨关会整包继承背包（`ObtainInventory`），章节级令牌必须显式清：

- `FZPlayEvents.WorldLoaded` → `ClearChapterState()`：`FZEvidence`(3)、
  `RedCard`、`FZStage1/2/3`、`FZGateLock`、`FZGateCool`、`FZMsg1/2/3`；
- 读档时引擎**不**触发 `WorldLoaded`（`src/events.cpp`），所以对存档安全；
- 漏清一项的典型症状：终端自认"已答过"不弹菜单、审判门天然开或永久锁死。
  自动化断言 `chapter/boss/full` 的 `reached wp 0 ... ev=0 red=0 st1=0 st2=0
  st3=0` 就是守这条线。

## 自定义实体编号（DoomEd）

| ednum | 含义 |
|---|---|
| 3920-3925 | 六个抉择终端（11/12 → 3920/3921，21/22 → 3922/3923，31/32 → 3924/3925） |
| 3930 | 证据箱（贴图沿用 Backpack，但编号绝不能是 8） |
| 3931 | 主谋证据 |
| 3932 | 简报"数据流" |
| TID 3942 / 3943 / 3944 | 终端 / 证据 / 简报，供探针与 `CreateActorIterator` 使用 |

编号必须 **< 32768**（引擎按有符号 16 位读）；`4`=Player 4 Start、`8`=Backpack、
`9`=ShotgunGuy、`3001-3005` 是原版怪，**不要**拿它们当占位编号用。
`CreateActorIterator(0)` 是空迭代器，探针必须给真实 TID。

## 测试接缝（全部是 cvar，默认关闭）

| cvar | 作用 |
|---|---|
| `fz_bot` | 1 = 开路线机器人 |
| `fz_bot_stop` | N = 走到第 N 个路点就停（-1 全程） |
| `fz_bot_timeout` | 秒，超过就 `FZBOT: TIMEOUT` 收工（默认 150） |
| `fz_bot_combat` | 1 = 自动瞄准最近怪物（开火由外部按住 Ctrl） |
| `fz_bot_god` | 1 = 每秒续 `PowerInvulnerable`（带怪跑图用） |
| `fz_bot_ammo` | 1 = 每秒补 24 霰弹 / 40 弹夹（带怪跑图用，否则清障时弹药会打光） |
| `fz_bot_killboss` | 1 = 进 Boss 房后 `DamageMobj` 打死 Baron |
| `fz_bot_skip_evidence` | 1 = 跳过三个证据凹室（反例用） |
| `fz_bot_retry` | 1 = 第一题答错后走回终端重答（配合 `fz_autoanswer 3`） |
| `fz_autoanswer` | 1 = 选项 A，2 = 选项 B，3 = 第一题首次答错、回访答对；0/未设 = 不自动作答 |


## 新增章节（程序视角的完整清单）

1. `tools/gen_maps.py`：`CHAPTERS` 加条目；`GATE_EDNUM` 加两个新终端编号；
   必要时改 `build_chapter()` 布局。生成期 `check_things()` 会断言物件数量与编号，
   不满足直接 `SystemExit`（别绕过它）。
2. `game/mapinfo/MAPINFO`：加 `map FZ0x`，上一章 `Next` 指向它；`episode`/章节菜单按需。
3. `fz_gates.zs`：
   - `FZGateData.Get` 加新门 ID（41/42…）；
   - `MsgText` 加简报/识破/正确；
   - `GateCorrect/GateDmg/GateAmb/GateAmbCount/GateMsgWrong/GateMsgRight/GateStage` 同步。
4. `fz_hud.zs`：`ObjectiveText()` 加章节分支。
5. `tools/gen_font.py`：重跑，收录新字符。
6. 测试钩子 `fzbot.zs`：`Wpx/Wpy` 路线 + `WorldLoaded` 的 mapname 判断。
7. `tools/fz_ctl.py`：新增/复用场景断言。
8. 文档：`docs/剧情.md`、`docs/协作/资源与命名规范.md` 的 ID 表。

## 扩展点

| 想加什么 | 建议做法 |
|---|---|
| 新骗术类型（如虚假贷款） | 复用 Gate 结构，只加数据与文案；敌人在 `GateAmb` 映射 |
| 小游戏/解谜 | 新 Actor + 自己的 `TryPickup`/`Tick`；用 token 与门系统串联 |
| 多结局 | `FZStage1-3` 之外加 `FZChoiceStats` token，出口前判定 |
| 存档 | 令牌是 Inventory，随存档保留；避免把状态存在 EventHandler 字段里 |
| 本地化 | 文案集中在 `MsgText`/语言表；不要散落在 Draw 里 |

## 约束（别踩）

- 地图保持 **vanilla 二进制格式**（UDMF 在 5.0.3 会崩）。
- ednum < 32768；纹理名 NUL 填充且必须存在于 IWAD。
- 抉择菜单文本 5 行上限；HUD 坐标是 320×200 虚拟空间。
- 门的 specials：26/27/28=蓝/黄/红 DR（会关），31/32/33=对应 D1（常开）；
  门面放 upper；双面门扇线不加 ML_BLOCKING。
- `Next` 只能是地图名；自定义 intermission 只用于 slideshow/finale。
- 自定义物件编号走 `GATE_EDNUM`/`ED_*` 常量表，**不要**用算术推导
  （`3920 + (gate_a - 11)` 曾让二三章终端变成证据箱编号，整章无抉择）。
- 章节级令牌必须在 `WorldLoaded` 里清零（跨关继承背包），漏一项就会软锁。
- 红卡必须同时校验 `FZEvidence >= 3` 与两道抉择的 Stage 令牌：只看证据数的话，
  三个证据箱就能独自开门，抉择失去否决权。
- 答错绝不能置 `done`：置了就是"答错即锁死本章"，只能靠重开过关。
- 测试接缝一律 cvar 开关，不默认生效；合成控制台按键不可靠，需引擎内效果时
  加 cvar 接缝而不是 console 命令。

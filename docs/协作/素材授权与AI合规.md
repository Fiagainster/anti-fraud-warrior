# 素材授权与 AI 合规

## 第三方组件（已在交付包 `LICENSES/` 内）

| 组件 | 许可 | 义务 |
|---|---|---|
| UZDoom 5.0.3 | **GPL-3.0** | 分发二进制需能提供对应源码；修改引擎需开源 |
| Freedoom 0.13.0（IWAD） | **BSD 3-Clause** | 保留版权声明与致谢；可商用 |
| Fusion Pixel 字体 | **SIL OFL 1.1** | 保留许可证；改名后再分发需注意保留声明 |

> 我们**没有修改引擎源码**；“对应源码”指 UZDoom 官方源码 + 我们的 PK3 脚本/地图生成器。
> 公开发布时在 README/关于页给出源码获取方式即可。

## 我们的内容

建议（待团队/单位确认）：

- 代码与工具（ZScript、Python）：**GPL-3.0**（与引擎一致，最省事）
- 剧情/美术/音频：**CC BY-NC-SA 4.0** 或单位指定的宣传素材授权
- 无论选哪种，都在仓库根目录放 `LICENSE` 并在 README 写明

## AI 使用政策

允许：
- 概念图、气氛参考、贴图底稿、配音预演、文案初稿
- 用 AI 做**辅助**（放大、去噪、配色建议）

要求：
1. 每个 AI 参与的文件在 `assets_src/CREDITS.md` 登记：
   `文件名 | 工具/模型 | 日期 | 提示词摘要 | 人工修改程度`
2. 最终交付素材必须经过人工修整（像素对齐、透明通道、风格统一）。
3. 不使用 AI 直接生成/仿制受版权保护的角色、品牌、真实人物肖像。
4. 不模仿在世艺术家的个人风格。
5. 涉及公安标识、警徽、真实机关名称的生成内容一律禁用，改由美术手工设计抽象化造型。

## 宣传口径与敏感内容

- 96110、报警/立案/资金冻结等表述以官方口径为准，发布前由宣传部门审校。
- 案例必须虚构化处理，不出现真实姓名、电话、身份证号、银行卡号。
- 不渲染血腥、猎奇、恐怖细节；受众包含学生。
- “诈骗话术”只做教学展示，避免可直接照搬的完整作案教程。

## 素材引入流程

1. 来源合法（自制 / 采购 / 明确许可的开源素材 / AI 辅助并登记）
2. 在 `assets_src/CREDITS.md` 登记
3. PR 里附许可截图或链接
4. 发布前由负责人复核 `LICENSES/`

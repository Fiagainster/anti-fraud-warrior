# 角色手册 · 音频

## 你会用到

| 工具 | 用途 |
|---|---|
| `tools/gen_sfx.py` | 程序化合成音效（纯 Python，不装任何音频软件） |
| `sfx_preview/` | 生成后的预听包，按类别分目录，`audition/` 是连播 |
| Audacity / Reaper | 真人配音的剪辑、降噪、响度归一 |
| ffmpeg | OGG 转码、循环标签、批量导出 |

## 目录与格式

```
game/sounds/          成品音效，44.1kHz / 16bit / 单声道 WAV
game/sounds/voice/    敌人配音（留空，待录）
game/sndinfo/SNDINFO  逻辑名 → 文件 的映射，打包成 PK3 根目录 SNDINFO
game/music/           BGM，OGG Vorbis q5（五首，已落地；改曲见 docs/音频设计.md §4.1）
assets_src/audio/     录音源文件（wav 48kHz / 24bit）
```

- 音效：44.1kHz / 16bit / **单声道**，峰值 ≤ −3dBFS，文件名 `fz_<事件>.wav`
- 配音：源文件 48kHz / 24bit；进游戏前转 44.1kHz / 16bit / 单声道，
  统一 −16 LUFS，前后各留 100ms 静音
- BGM：OGG Vorbis q5，44.1kHz 立体声，−16 LUFS，真峰值 ≤ −1.5 dBFS

## 接入方式（程序配合）

- 简单音效：事件点 `A_StartSound("fz/gate_open", CHAN_AUTO)`，或物品的
  `Inventory.PickupSound`；全局/UI 事件由 HUD 侧触发。
- 敌人语音：actor 的 `Default` 块里挂 `SeeSound` / `PainSound` / `DeathSound`，
  AI 与状态机一行不用改。
- 所有声音在 `SNDINFO` 注册，音量统一在 `SNDINFO` 里用 `$volume` 调。
- 武器音效在 `fz_weapons.zs` 的 Fire 帧里播放，不要改回 `A_FirePistol`
  （那样会绕过自定义音效）。

## 验收

1. 游戏内实际听感（关闭 `-nosound`），无爆音/削波；
2. 音效与画面事件同步（±50ms）；
3. 字幕与配音内容一致；
4. 源文件进 `assets_src/audio/`，`CREDITS.md` 登记来源与授权。

## 注意

- 不使用未授权的商业音乐/影视音效；
- 配音演员需签署使用授权（范围内宣传用途）；
- AI 语音只用于预演，正式版建议真人配音（合规与可信度）。

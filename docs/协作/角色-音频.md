# 角色手册 · 音频

## 你会用到

| 工具 | 用途 |
|---|---|
| Reaper / Audacity | 剪辑、降噪、响度归一 |
| ffmpeg | 格式转换、批量导出 |
| Blender（可选） | 简单拟音/合成 |

## 目录与格式

```
assets_src/audio/
  voice/     配音源文件（wav 48kHz 24bit）
  sfx/       音效（wav 44.1kHz 16bit mono）
  music/     BGM（ogg，循环点标注）
```

导入游戏时：

- 音效：44.1kHz / 16bit / **单声道**，峰值 ≤ -3dBFS，命名 `fz_<事件>.wav`
- 配音：48kHz / 24bit / 单声道，响度 **-16 LUFS**，前后各留 100ms 静音
- BGM：OGG Vorbis q5，循环点写进文件名/说明（如 `ch1_loop_0-32s.ogg`）

## 命名（进 SNDINFO 的名字）

- 事件音：`fz/gate_open`、`fz/gate_right`、`fz/gate_wrong`、`fz/evidence`、`fz/case_closed`
- 配音：`fz/voice/ch1_brief1`（章_类型_序号）
- 敌人：`fz/enemy/scammer/sight`、`.../pain`、`.../death`

## 需要做的第一批声音（按收益）

1. 抉择结果：正确（清脆正向）、错误（低频警示）——玩家反馈的核心
2. 证据入手、红卡获得、审判门开启
3. Boss 出场与环境低鸣（第一章"机房"氛围）
4. 结算页短提示音
5. 配音（后做）：简报旁白、Boss 台词、96110 提示音

## 接入方式（程序配合）

- 简单音效：在 ZScript 事件点 `A_StartSound("fz/gate_right", CHAN_VOICE)`；
  全局/UI 事件可由 HUD 侧触发。
- 配音：先用字幕（现有横幅）承载，音频后挂；避免音频与字幕不同步。
- 所有声音在 `SNDINFO` 注册（PK3 根目录 `SNDINFO`），音量统一在 `SNDINFO` 里定。

## 验收

1. 游戏内实际听感（-nosound 关闭），无爆音/削波；
2. 音效与画面事件同步（±50ms）；
3. 字幕与配音内容一致；
4. 源文件进 `assets_src/audio/`，`CREDITS.md` 登记来源与授权。

## 注意

- 不使用未授权的商业音乐/影视音效；
- 配音演员需签署使用授权（范围内宣传用途）；
- AI 语音只用于预演，正式版建议真人配音（合规与可信度）。

# 角色手册 · 剧情 / 文案

## 素材位置

- 世界观与三章设定：`docs/剧情.md`（接着往下写，不要另起炉灶）
- 游戏内实际文本：`game/zscript/fz_gates.zs`
  - `FZGateData.Get(id)`：抉择门标题/场景/两个选项
  - `FZGateData.MsgText(id)`：简报、识破、正确、事件横幅
- 结算页文案：`tools/gen_intermission.py`（FZBKGRD1-3 图上的字）
- 引擎字符串覆盖：`game/language/language.txt`

## 文本长度硬约束（排版会溢出）

| 位置 | 上限 | 说明 |
|---|---|---|
| 抉择场景 | **5 行 × ≤22 汉字** | 菜单高度 200，超过会压到底部提示 |
| 选项文字 | ≤12 汉字 | 居中显示，太长会顶到边 |
| 横幅消息 | 3 行 × ≤22 汉字 | 自动换行按 300px 计算 |
| 目标行 | ≤8 汉字 | HUD 底部一行 |
| 章节标题 | ≤12 汉字 | 主菜单/结算页 |

> 规则不是死的：改完文案跑 `python tools\fz_ctl.py menu` 看截图，确认没溢出再提交。

## ID 规范

| 范围 | 用途 |
|---|---|
| 101-103 / 201-203 / 301-303 | 各章简报三条 |
| 111/121/… / 211/221/… | 各章"识破"（选错后的教育文案） |
| 112/122/… | 各章"正确"反馈 |
| 901-903 | 全局事件（证据链、主谋伏法、结案） |
| 9xx 其余 | 预留 |

新增章节按 `<章>0x` 顺延，先在本表登记。

## 写作要求

1. **先给后果，再讲道理**：每个抉择都要让玩家感到"选错真的会损失"。
2. **口语化、短句**：玩家在战斗节奏里读字，不要长难句。
3. **知识点必须可执行**：写"挂断并拨 96110"，不要写"提高警惕"。
4. **不恐吓、不猎奇**：面向学生/社区，避免血腥细节与真实案件隐私。
5. **96110/公安口径**：涉及报警、立案、资金冻结的表述必须按官方口径，
   发布前走审校（见《素材授权与AI合规》）。

## 流程

1. 先在 `docs/剧情.md` 写完整小传与骗术拆解；
2. 再落到 `fz_gates.zs` 的字符串；
3. `python tools\gen_font.py` 重生成字体（新字会自动进图集）；
4. `python tools\fz_ctl.py menu` 截图验收排版；
5. 文案 Review：至少 1 人校对 + 1 人合规审校。

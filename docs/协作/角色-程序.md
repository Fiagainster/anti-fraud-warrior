# 角色手册 · 程序（ZScript / 工具链）

## 代码地图

| 文件 | 职责 |
|---|---|
| `game/zscript/fz_defs.zs` | 库存令牌、消息载体、抉择终端 Actor、证据/主谋掉落、简报流 |
| `game/zscript/fz_gates.zs` | 门配置与文案、抉择菜单 UI、对错结算（NetworkProcess） |
| `game/zscript/fz_hud.zs` | 状态栏：数值行、目标、消息横幅、红卡指示、菜单触发 |
| `game/mapinfo/MAPINFO` | statusbarclass / eventhandlers / doomednums / 地图与章节链 |
| `game/language/language.txt` | 引擎字符串中文覆盖（每条以 `;` 结尾） |
| `game/zscript.txt` | 脚本入口与 include 顺序 |
| `tools/gen_maps.py` | 原生 WAD 地图生成器（布局 + 校验） |

数据流（一次抉择）：

```
玩家碰到 FZGateTerminal
  -> TryPickup 给 FZGateLock(带 GateId)
  -> HUD(ui) 的 CheckGateMenu 发现 lock -> new FZChoiceMenu -> ActivateMenu
  -> 玩家回车 -> Commit -> SendNetworkEvent('FZGateChoice', gid, choice)
  -> FZPlayEvents(play) 结算：发令牌/发盾/扣血/伏击 -> 移除 lock + 给 cool
```

## ZScript 铁律（都是编译/运行时踩出来的）

1. **作用域**：EventHandler 默认 play，`UiTick` 是 ui；跨域赋值报
   "Expression must be a modifiable value"。ui 侧状态用 `ui` 字段。
2. **没有顶层自由函数**：函数必须挂在类里（`static` play 方法）。
3. **struct 赋值/返回未实现** → 用返回 primitive 的 switch 函数。
4. **状态必须分行**：`frame;` 与 `Stop;` 不能同一行。
5. **`CreateActorIterator(0)` 是空迭代器**（源码 id==0 直接返回 null）；
   遍历实体用 TID 或 `ThinkerIterator.Create('Actor')`。
6. **`Actor.Spawn`** 在 Actor 作用域；EventHandler 里用 `Actor.Spawn(...)`。
7. **PlayerEvent 字段**是 `e.PlayerNumber`；ConsoleEvent 是 `e.Args[0]`。
8. **CountInv**（不是 CountInventory）；库存链是 `.Inv`。
9. **自定义配置会清空默认绑定**：不要手写精简 config（ESC/控制台会消失）。
10. **ednum < 32768**；THINGS options 用 7（bit16=仅多人）。

## 编码风格

- 文件头写用途与作用域说明；关键"为什么"写注释（坑位优先）。
- 变量/函数英文，玩家可见文本中文；文本统一走 `FZGateData.MsgText` 或语言表。
- 一屏能读完的函数优先；复杂逻辑拆 `private` 辅助函数。
- 测试专用逻辑一律用 cvar 开关（`fz_bot` / `fz_autoanswer`），不要默认生效。

## 新增系统的最小闭环

1. 令牌/实体定义（`fz_defs.zs`）
2. MAPINFO 注册（doomednums / eventhandlers）
3. 玩法逻辑（play 作用域）
4. HUD/菜单呈现（ui 作用域）
5. 文案（`MsgText` + `gen_font.py` 重生成）
6. 自动化：钩子里加 cvar + 探针/断言

## 测试闸门（改完必跑）

```powershell
python tools\fz_ctl.py check    # -errorlog batchrun 编译预检，无弹窗
python tools\fz_ctl.py tour     # 第一章路线/证据/双门
python tools\fz_ctl.py door     # 红卡门
python tools\fz_ctl.py exit     # 出口 → 结算 → 第二章
python tools\fz_ctl.py full     # 三章马拉松（较慢）
```

注意：自动化按 **PID** 锁定自己启动的窗口，不会误操作你正在玩的游戏；
测试时会短暂接管键鼠，跑之前先关掉自己的游戏窗口。

## 性能与兼容

- 避免每 tick 遍历全图实体（用 TID/事件）；HUD 每帧只做轻量计数。
- 新增贴图注意尺寸 2 的幂，避免运行时缩放。
- 地图源码是 `tools/gen_maps.py`；产物默认 UDMF（`ZDoomTranslated` 命名空间，
  装成 WAD lump），`--format vanilla` 仍可出旧的二进制。别把地图改成 PK3 里的
  散装 `.map` 文件——那条路径在 5.0.3 上是崩的。

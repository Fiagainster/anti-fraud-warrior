# 角色手册 · 关卡 / 地图

## 两种工作流

### A. 程序化地图（推荐，当前主用）

地图由 `tools/gen_maps.py` 生成原生二进制 WAD（`game/maps/FZn.wad`）。
**生成器就是源码**，改布局 = 改 Python，产物不入库。

关键结构：

```python
# 扇区（地板高、顶高、地板扁平、顶扁平、亮度）
brief = m.sector(0, 128, floor, ceil, 190)
# 房间边界：一次调用画完，所有缺口在同一调用里给全
m.rect_walls(0, 0, 512, 512, brief, wall, gaps={"e": (192, 320)})
# 连接线（两扇区之间）
m.open_v(512, 192, 320, sec_east=c1, sec_west=brief)
# 门：lock 1=红 2=黄 3=蓝（生成器映射到 D1 常开门）
m.door(2432, 192, 2464, 320, LOCK_RED, sec_west=a2, sec_east=boss)
```

硬规则（都踩过坑）：

1. **房间边界只画一次**；重复调用会把先前留的门洞封死（空气墙）。
2. 缺口用世界坐标区间给全；凹室必须在主房间之外、共享边线，扇区不得重叠。
3. 竖直边绕向：y 递减（向南）时正面朝西——开关/门面要朝向玩家。
4. 贴图/扁平名必须在 IWAD 里存在（生成时校验），名称 NUL 填充。
5. 自定义 ednum < 32768；新增编号先登记到《资源与命名规范》。
6. 门面图形放 sidedef 的 **upper** 层；双面门扇线不加 ML_BLOCKING。

### B. 手工地图（可选）

复杂关卡可用 **Ultimate Doom Builder**：

- 新建地图格式选 **Doom: Doom 2 (Doom format)**（**不要 UDMF**，5.0.3 的 UDMF 加载器会崩）。
- 只用 Freedoom IWAD 里存在的贴图名；自定义贴图需先在 `game/graphics/` 注册。
- 保存后把 WAD 放 `assets_src/maps_src/`，命名 `FZ0x_<简述>.wad`，并在同目录写 `README.md` 说明挂载方式。
- 程序会把它接进 `build/maps/` 或 PK3 流程，并跑同样的验收。

## 新增一章的步骤

1. `tools/gen_maps.py` 的 `CHAPTERS` 增加一条：`name`、`palette`（墙/地板/顶）、`enemies1/2`、`boss_adds`、`gate_a/gate_b`。
   - 复用现有布局即可先跑通；新布局再改 `build_chapter()`。
2. `game/mapinfo/MAPINFO`：加 `map FZ04 "第四章：…" { Next=… Sky1=… Music=… }`，
   上一章 `Next` 指向它；更新 `episode`（如需章节菜单）。
3. `game/zscript/fz_gates.zs`：新增门 ID（如 41/42）与文案；`GateCorrect/GateStage/...` 同步。
4. `game/zscript/fz_hud.zs`：`ObjectiveText()` 增加新章节分支。
5. 字体：跑 `python tools\gen_font.py`（自动收集新文案字符）。
6. 测试钩子 `tools/testhooks/bot/zscript/fzbot.zs`：为新章加路线路点（布局相同可复用，改 mapname 判断即可）。
7. 验收：`fz_ctl check` → `build` → 新章场景（可先 `+map FZ04` 手动跑）→ `tour` 不回归。

## 关卡设计清单（发布前）

- 出生点 128 单位内无遮挡；主路径宽度 ≥ 96（门洞 ≥ 64）。
- 每个抉择终端前有 ≥ 128×128 的停留空间（弹菜单时玩家会被暂停）。
- 证据点可达且不被敌人堵死；Boss 房有回旋空间。
- 出口前有清晰视觉引导（开关墙/亮度对比）。
- 亮度不低于 150 的主路径，避免"看不清路"。

## 验收命令

```powershell
python tools\gen_maps.py      # 生成 + IWAD 名校验
python tools\build.py         # 打包
python tools\fz_ctl.py tour   # 第一章回归（新章先手动或加场景）
```

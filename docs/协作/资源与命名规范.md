# 资源与命名规范

## 目录边界

| 路径 | 入库 | 说明 |
|---|---|---|
| `game/` | ✅ | ZScript、MAPINFO、语言表、字体图集、PNG 图形（构建输入） |
| `game/maps/*.wad` | ❌ | 由 `tools/gen_maps.py` 生成；手工 WAD 放 `assets_src/maps_src/` 并登记 |
| `assets_src/` | ✅（LFS） | Blender/贴图/音频**源文件**，见下 |
| `tools/` | ✅ | 生成器、构建、测试、发布脚本 |
| `docs/` | ✅ | 文档与截图 |
| `config/` | ✅ | 随包配置（绑定/分辨率/语言），**不要手写精简配置** |
| `vendor/` | ❌（仅 manifest） | 引擎/IWAD/字体；用 `tools/fetch_vendor.py` 导入 |
| `source/` | ❌ | 参考源码（1997 DOOM/UZDoom trunk），本地保留即可 |
| `build/` `dist/` | ❌ | 构建与交付产物 |

## assets_src 结构

```
assets_src/
  blender/       .blend 源文件（敌人、武器、徽标、道具）
  textures/      墙面/地面/天花源图（krita/psd/aseprite）
  ui/            HUD/标题/菜单/结算页源文件
  audio/         音效/配音/BGM 源文件（wav/ogg）
  maps_src/      手工地图源文件（UDB .wad/.map + 说明）
  CREDITS.md     每个外部素材：来源、作者、许可证、AI 参与情况
```

## 命名

- 全小写 + 下划线，不用中文/空格：`enemy_scammer_dir3_walk2.png`
- 引擎资源名（会被 WAD/PK3 引用）用**大写短名**且不超过 8 字符：
  - 贴图/扁平：`FZWALL1`、`FZFLR1`（IWAD 里已存在的名字也可直接用）
  - 图形 lump：`FZPANEL`、`FZBKPT`、`FZBKGRD1`
- 敌人 sprite 命名：`enemy_<角色>_<方向0-7>_<动作><帧>.png`，
  导入游戏时映射为 Doom sprite lump（如 `SCAM A1`），映射表写在 `assets_src/blender/README.md`。

## DoomEd 编号（THINGS type）

- 自定义物件必须 **< 32768**（引擎按有符号 16 位读，超出会变成负数被丢弃）。
- 当前占用：

  |---|---|
  | 3920-3925 | FZGate11/12/21/22/31/32 抉择终端 |
  | 3930 | FZEvidencePickup 证据箱 |
  | 3931 | FZMasterProof 主谋证据 |
  | 3932 | FZBriefingActor 简报流 |
- 新增物件请从 **3940** 起顺序申请，并同步更新 `game/mapinfo/MAPINFO` 的 `doomednums` 与本文档。

## 贴图/扁平规则（血泪教训）

1. 名称必须 NUL 填充（生成器已处理）；空格填充会导致查不到 → 棋盘格。
2. 名字必须存在于 IWAD 或我们自己的 PK3；`gen_maps.py` 会在生成时对照 IWAD 校验。
3. 门的正面图形必须放 **upper** 纹理层，middle 会透明（看起来像空气墙）。
4. 双面门扇线**不要**加 ML_BLOCKING(1)。

## 字符串/ID 规范

- 抉择门 ID：`11/12`（第一章）、`21/22`（第二章）、`31/32`（第三章），十位=章、个位=第几道。
- 消息 ID：`101-103/201-203/301-303` 简报；`111/121/…` 识破；`112/122/…` 正确；`9xx` 全局事件。
- 新增章节沿用：`<章>0x` 规则，避免与现有冲突。

## 提交大文件

- `.blend/.psd/.kra/.wav/.ogg` 走 Git LFS；提交前 `git lfs install`。
- 单文件 >50MB 先找程序商量（可能要外链 + 校验和）。

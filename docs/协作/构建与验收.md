# 构建与验收

## 日常命令

```powershell
python tools\doctor.py            # 环境自检
python tools\build.py             # 打包 game/ -> build/fanzha-demo.pk3（缺地图会自动生成）
run.bat                           # 游玩（config/uzdoom.cfg，窗口 1280x720）

python tools\fz_ctl.py check      # 编译预检：脚本/MAPINFO 错误在启动前拦下，不弹窗
python tools\fz_ctl.py tour       # 第一章全程（9 项断言）
python tools\fz_ctl.py door       # 红卡审判门 → Boss 房
python tools\fz_ctl.py exit       # 出口 → 结算页 → 第二章
python tools\fz_ctl.py menu       # 只展示抉择菜单（拍排版）
python tools\fz_ctl.py gate       # 只到第一道终端
python tools\fz_ctl.py esc        # ESC 主菜单开合（长按 2 秒）
python tools\fz_ctl.py full       # 三章马拉松（慢）

python tools\make_dist.py         # 出交付包 dist/fanzha-demo-v0.1{.zip,/}
```

产物与截图：

- `build/fanzha-demo.pk3`、`build/maps/*.wad`
- `_staging\fztest\bot_shots\`：自动化截图（menu_*_before/after、door_*、99_final）

配置文件分工（重要）：

- `config/uzdoom.cfg` 是**模板，只读**，改动要提交进 git；
- `run.bat` 首次启动把它复制成 `build/uzdoom.cfg`，引擎之后只改写后者；
- 别把 `-config` 指回 `config/`，否则引擎每次退出都会回写窗口位置和时间戳，
  工作区永远是脏的。要恢复默认设置：删 `build/uzdoom.cfg` 再启动。

## 自动化是怎么工作的

1. `fz_ctl` 构建 PK3 + 测试钩子 `tools/testhooks/bot/`（引擎内路线机器人）。
2. 先用 `-errorlog` 跑一次 **batchrun 预检**：只编译脚本/MAPINFO，然后退出（返回码 1337），
   错误只打印不弹窗——坏脚本进不了游戏。
3. 正式运行：窗口化启动，机器人用真实物理走位；`fz_ctl` 用真实键鼠（SendInput 扫描码）
   处理过场/门/开关，菜单由引擎内 cvar `fz_autoanswer` 作答。
4. 截图 + 日志断言；到终点立刻退出（事件驱动，不空等）。

## CI（GitHub Actions）

`.github/workflows/build.yml` 在 Windows runner 上跑五步：

1. `compileall tools`（Python 语法）
2. `tools/ci_static.py`（include 存在性、MAPINFO 地图链、doomednums 类、字体引用、run.bat 纯 ASCII、绝对路径泄漏）
3. 下载 **Freedoom 0.13.0**（BSD）并用 `fetch_vendor.py` 导入
4. `tools/gen_maps.py`——真的生成三章地图，同时对照 IWAD 校验每个纹理名
5. `tools/build.py`——真的打包 PK3

第 5 步带 `FZ_ALLOW_NO_FONTS=1`：CI 拿不到 Fusion Pixel 的 ttf，所以**字图集
不在 CI 验证范围内**（打包会打印 WARN）。这个开关只给 CI 用，正式出包前必须
本地跑 `gen_font.py`，否则 HUD 一个字都显示不出来。

引擎相关的东西（ZScript 编译、HUD 字体、走位回归）需要真实 Vulkan 环境，
**只能在本地或专用测试机跑**：`fz_ctl check` / `tour` / `door`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动随机崩溃 | 删 `%LOCALAPPDATA%\doom\uzdoom\vulkanpipelinecache` |
| 脚本改了没生效 | 先 `build.py`，确认 `build/fanzha-demo.pk3` 时间戳更新 |
| 地图变化没体现 | `build/maps/*.wad` 是拷贝产物，重新 `build.py` |
| 自动化截图是黑屏 | 窗口被最小化/被别的窗口遮挡；确保测试窗口在前台 |
| ESC 打不开菜单 | 长按约 2 秒；短按会被按键重复机制吞掉 |
| 标题页自己动起来 | Freedoom 旧格式 demo 播放，按任意键回标题（已知行为） |

# 配音设计：6 个敌人 × 3 个槽位

> 一句话：**不做对话系统，只做 18 条敌人短句**，挂在 actor 的
> `SeeSound` / `PainSound` / `DeathSound` 上，AI 与状态机一行不用改。

这份文档是配音的**执行手册**：台词、文件命名、SNDINFO、TTS 占位、录音与后期、集成、验收。
"为什么要做、声线为什么这么定"的背景在 [音频设计.md](音频设计.md) §5。

## 1 范围

**做**

- 6 个角色 × 3 个槽位 = **18 条**短句；
- 每条 0.8–1.5 秒（上限见 §4），太长会在战斗里拖节奏；
- 文件、SNDINFO、actor 槽位、后期规范一次定死，之后换人换词都只动文件。

**不做**

- 不做对话系统、不做多段台词、不做剧情语音；
- 不加新 actor、不改 AI、不改状态机、不碰 `fz_gates.zs`；
- 不做字幕（引擎没有这个机制；真要做，得复用简报 banner 那一套，另开需求）。

**触发方式（引擎原生，不需要脚本）**

| 槽位 | 触发点 | 引擎行为 |
|---|---|---|
| `SeeSound` | `A_Look` 第一次看见玩家 | 走 `CHAN_VOICE`，正在播的语音会被打断 |
| `PainSound` | `A_Pain` | 同上，受 `PainChance` 控制频率 |
| `DeathSound` | `A_Scream` | 同上，死亡只响一次 |

## 3 声线设计

| 角色 | 一句话 | 音色 | 语速 | 情绪基调 | 不要做成 |
|---|---|---|---|---|---|
| 刷手（Shill） | 地推楼里拉人刷单的"托" | 中高、偏亮、有点油 | 快，但不赶 | 热情过头，尾音上扬，像在叫卖 | 不要凶、不要阴，他是"笑面" |
| 跑分马仔（Runner） | 洗钱链条最末端 | 偏年轻、沙 | 最快 | 急躁、压着嗓子、随时要炸 | 不要念稿，不要清楚，要有"喘" |
| 黄牛（Scalper） | 荐股群主 | 中低、带笑 | 慢 | 阴狠、慢条斯理、居高临下 | 不要吼；越平静越吓人 |
| 黑市掮客（Broker） | 中间人 / 打手 | 低、闷 | 中偏慢 | 冷淡、含糊、懒得说 | 不要字正腔圆，尾音可以吞掉 |
| 假警察（FakeCop） | 冒充公检法 | 中、正、亮 | 中 | 官腔、命令式、居高临下 | 不要真的正气；是"假的权威" |
| 影子会长（Chairman） | 幕后老板 / Boss | 很低、稳 | 慢 | 平静、不吼、话少 | 不要狰狞；他不需要生气 |

三条通用规则：

1. **身份靠语气不靠台词**：18 条里没有一个字提到"我是骗子"，玩家要听出来。
2. **短**：SIGHT 是"发现你"的一瞬间，超过 1.5 秒就变成过场。
3. **不要齐**：六个角色不能听起来像同一个人的六种语速——音色/口音/气息至少差一项。

## 5 占位方案：TTS 先跑通管线

真人录音要等人，但"人声进游戏"这条链路可以先验证。**占位的意义是把槽位、音量、衰减跑通，
声线好坏等真人**——真人到位后同名替换文件，代码与 SNDINFO 一行不动。

### 5.1 用什么

DSH 的 any-audio 插件，Edge TTS（不需要 key、不需要代理实测可用；输出 48 kHz 单声道 16-bit）。
生成后在剪辑台里可以逐条试听、调片段增益，再走 §7 的后期导出。

### 5.2 角色 → 声线参数（待试音确认）

| 角色 | Edge 声线 | rate | pitch | 依据 |
|---|---|---|---|---|
| Shill | `zh-CN-YunxiNeural`（云希，偏年轻） | `+30%` | `+3Hz` | 亮、快、尾音能挑起来 |
| Runner | 云希（同上） | `+50%` | `+8Hz` | 和 Shill 同音色，全靠速率/音高区分"急" |
| Scalper | `zh-CN-YunjianNeural`（云健，偏沉稳） | `-18%` | `-4Hz` | 慢下来才有"阴" |
| Broker | 云健 | `-22%` | `-10Hz` | 更低压，接近含糊 |
| FakeCop | `zh-CN-YunyangNeural`（云扬，新闻腔） | `+8%` | `0Hz` | 新闻腔天然像"官腔" |
| Chairman | 云健 | `-15%` | `-8Hz` | 平静、字尾压住 |

### 5.3 实测（4 条样音，2026-11-23）

| 台词 | 参数 | 实测 | 要求 | 是上限的 |
|---|---|---|---|---|
| 亲，刷单返利，稳赚不赔！ | 云希 +30% | 2.93 s | ≤1.2 s | 2.4 倍 |
| 快点！流水要断了！ | 云希 +45% | 2.26 s | ≤1.0 s | 2.3 倍 |
| 这一单，你输不起。 | 云健 −12% | 2.76 s | ≤1.5 s | 1.8 倍 |
| 站住！配合调查！ | 云扬 +5% | 2.50 s | ≤1.0 s | 2.5 倍 |

**TTS 天生比真人慢 1.5–2 倍**：它按标点停、每个字都念全，而真人喊话是吞音+抢气口。
占位有两条路，任选：

1. **缩文本**（推荐）：占位只念关键词，例如第 1 条念"稳赚不赔！"、第 4 条念"流水要断了！"。
   占位只为验证管线，不承担"台词对不对"；
2. **推速率**：`+60%~+80%` 能把时长压到 1.5 秒内，但云希会开始发尖，听感明显是机器。

真人录音不受这条影响，按 §4 的上限念即可。

### 5.4 占位的局限（别当成品交付）

- 没有表演，重音和停顿是算法给的；
- 六个角色实际只有三把嗓子（云希/云健/云扬），靠参数硬分；
- 涉及"我操"这类词，TTS 可能念成英文或被过滤，需实测；
- **占位不进 `CREDITS.md` 的最终名单**，但要在那里注明"当前为 AI 占位，真人录音待补"。

## 6 录音规范（交给配音者）

- 44.1 kHz / 16-bit / **单声道** WAV；
- 近麦 10–15 cm，加防喷罩；房间越干越好（衣柜、被褥都行）；
- 峰值不超过 −3 dBFS，底噪低于 −50 dBFS；
- 每条**前后各留 0.2 秒静音**，不要自己加混响/压缩/降噪——后期统一做；
- 一条不过就整条重录，**不要拼接**；
- 每条录 3 遍，文件名后加 `_a/_b/_c`，我们挑一条进库；
- 交付时附一张表：文件名 → 实际时长 → 自评（有没有喷麦/口水音）。

> 只有一个人也能开工：先录 Shill 的 3 条（§10 的 R1），确认声线和响度方向再铺开。

## 7 后期处理（统一做，不要让配音者做）

目标：**44.1 kHz / 16-bit / 单声道 / −16 LUFS / 峰值 ≤ −3 dBFS**，首尾各留 0.1 秒静音。

一条命令跑完（ffmpeg，链条可按听感微调）：

```powershell
ffmpeg -y -i raw.wav -af "silenceremove=start_periods=1:start_threshold=-45dB,areverse,silenceremove=start_periods=1:start_threshold=-45dB,areverse,highpass=f=80,acompressor=threshold=-18dB:ratio=3:attack=5:release=80,loudnorm=I=-16:TP=-3:LRA=7" -ar 44100 -ac 1 -c:a pcm_s16le FZSHL_SIGHT.wav
```

- 掐静音要在**高低通之前**做，否则底噪会把静音判据顶高；
- `highpass=80` 去掉近麦的隆隆声；`acompressor` 让喊叫不炸、耳语也听得见；
- 饱和（可选）：`asoftclip` 或 `compand`，目的是让声音"旧"一点，别加过量；
- 处理完用 `ffmpeg -af ebur128` 复测响度，**不要凭感觉**。

### 8.3 actor 槽位（`game/zscript/fz_actors.zs`）

每个类**已经**有 `Default` 块，往里加三行即可（不要新起一个 `Default` 块）：

```zs
class FZShill : ZombieMan replaces ZombieMan
{
	Default
	{
		Health 32;
		// …原有内容不动…
		SeeSound   "fz/voice/shill_sight";
		PainSound  "fz/voice/shill_pain";
		DeathSound "fz/voice/shill_death";
	}
```

六个类一一对应：

| 类 | 三行逻辑名前缀 |
|---|---|
| `FZShill` | `fz/voice/shill_*` |
| `FZRunner` | `fz/voice/runner_*` |
| `FZScalper` | `fz/voice/scalper_*` |
| `FZBroker` | `fz/voice/broker_*` |
| `FZFakeCop` | `fz/voice/cop_*` |
| `FZChairman` | `fz/voice/chairman_*` |

### 8.4 音量层级（与混音表一致）

| 层 | 目标 | 说明 |
|---|---|---|
| 武器 | −8 dBFS | 最响，压过一切 |
| **敌人语音** | **−10 dBFS** | 比枪低 2 dB，听得清但不抢 |
| 拾取 / UI | −14 dBFS | |
| 环境 / 门 | −18 dBFS | |
| 音乐 | −18 dBFS | 已按 −16 LUFS 归一，游戏内靠 `snd_musicvolume` 再降 |

语音走 `CHAN_VOICE`，**同一条通道只播一条**——乱战时不会六个怪一起喊。

## 9 验收

| # | 查什么 | 怎么查 | 判据 |
|---|---|---|---|
| 1 | 18 个文件都在、格式对 | 脚本读 `game/sounds/voice/` | 44.1k / 单声道 / ≤ 上限 |
| 2 | SNDINFO 引用的文件都存在 | 打包后列 pk3 条目 | 18/18 |
| 3 | 六个角色都能触发 | `python tools\fz_ctl.py chapter FZ01` + 手动遇敌 | 日志无 `sound … not found` |
| 4 | 音量不炸、不抢枪声 | 实机开一枪 + 同时叫 | 语音比枪低，不削波 |
| 5 | 距离衰减 | 门外/近身各听一次 | 近清远糊 |
| 6 | 台词与文档一致 | 人工听 | 与 §4 逐字一致 |
| 7 | 不再出现原版怪叫 | 六种怪各杀一只 | 没有任何 Freedoom 叫声 |

测语音时**不能开 `-nosound`**：`fz_ctl` 的所有场景都带这个参数，
它只能验"脚本没炸"，验不了声音。

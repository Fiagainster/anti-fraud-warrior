# 反诈战士 · 垂直切片方案（v0.1）

> **2026-11-19：Stage 0 已完成。** 中文 HUD、中文主菜单、305 字像素字体已可运行，见根目录 `README.md`。
>
> 定位：公安/社区/校园反诈宣传，面向年轻人/学生。
> 目标：先用 10 分钟 demo 验证“Doom 式战斗 + 识骗抉择 + 案件复盘”，再决定是否扩团队做完整版。

---

## 1. 成功标准

Demo 不追求“完整”，只验证四件事：

1. 目标机器上中文清晰，无乱码、无错误断行。
2. 玩家 10 分钟内能说出该骗术的至少 2 个关键识别点。
3. 3–5 名非开发用户试玩后，至少 2 人能复述“垫付/共享屏幕”的风险。
4. 目标硬件（学校/展馆旧电脑）能稳定运行。

只要这四条过，就值得进入内容生产；过不了，及时换 Godot/H5，损失可控。

---

## 2. Demo 范围（只做这些）

### 案件
**刷单返利**（学生高发，认知门槛低，适合 10 分钟讲清）。

### 内容量
- 1 张地图，10–12 分钟。
- 2 种普通敌人 + 1 个 boss：
  - **托儿**：远程扔“好评/返利截图”，制造从众压力。
  - **假客服**：近战“话术”，要求下载会议软件、共享屏幕。
  - **群主（boss）**：召唤托儿、投放“连单任务”。
- 2 把武器：
  - **反诈喇叭**：范围警示/击退，适合清群。
  - **证据链**：单体锁定/高伤，打 boss。
- 1 个道具：**国家反诈中心 APP**，扫描陷阱、显示隐藏线索。
- 2 个抉择门：
  1. 第一单返利到账后，是否垫付 299 元“连单任务”。
  2. 客服要求“共享屏幕/下载会议软件”时，是否照做。
- 1 个结算页：识破点、错误选择、知识点、评级、重玩。

### 明确不做
多关卡、存档、联机、配音、启动器、成就、知识库、排行榜。这些留到 demo 通过之后。

## 3. 10 分钟流程

| 时间 | 内容 | 目的 |
|---|---|---|
| 0:00–0:30 | 开场简报：卧底进入“刷单任务群” | 交代目标 |
| 0:30–2:30 | 教学战斗：打托儿，学喇叭/证据链 | 教会操作 |
| 2:30–4:00 | 第一抉择：是否垫付 299 元 | 第一次识骗 |
| 4:00–7:00 | 中段战斗：假客服出现，地图推进 | 保持节奏 |
| 7:00–8:30 | 第二抉择：是否共享屏幕 | 第二次识骗 |
| 8:30–11:00 | Boss 战：群主 | 高潮 |
| 11:00–12:00 | 结算/知识点 | 教学闭环 |

> 抉择门要“即时反馈”：选错立刻触发伏击/扣警惕值/陷阱；选对打开捷径或获得情报。不要只靠结算页说教。

## 4. UI 清单

### 游戏内
- HUD：警惕值、证据、案件进度、96110 提示、字幕区。
- 主菜单：开始行动、操作说明、退出（demo 版）。
- 结算页：识破/失误/知识点/重玩。
- 中文字幕：所有关键台词，字号要大，关键词变色。

### 游戏外（demo 阶段先不做）
- 案件档案、反诈知识库、成绩报告、教师/展馆看板。
- 这些用 Tauri/Electron 启动器做，不要塞进 Doom 菜单。

### 字体
- Fusion Pixel 10px Proportional（OFL）子集，生成 Unicode PNG 字体。
- 只打包游戏实际用到的字符，控制在 1500–2500 字。
- 中文无空格，必须测试自动换行；必要时手动断行或写 ZScript 换行助手。

## 5. 技术栈

| 项 | 选择 | 备注 |
|---|---|---|
| 引擎 | UZDoom 5.0.3（备选 GZDoom 4.14.2） | 锁定版本，不追更新 |
| 资产底座 | Freedoom Phase 1 | BSD 类自由许可，可改可商用 |
| 地图 | `tools/gen_maps.py` 生成 WAD（**UDMF / `ZDoomTranslated`**，可 `--format vanilla` 回退） | 生成器即源码，地图是纯文本可 diff；手工关卡用 UDB 时选 UDMF（**别存成 PK3 里的散装 `.map`，5.0.3 会崩**） |
| 资源包 | SLADE | 编辑 PK3/WAD |
| 脚本 | ZScript + ACS | HUD、菜单、对话、结算 |
| 字体 | Python + Pillow + fontTools | 生成 Unicode PNG 子集 |
| 美术 | Pixelorama（手工像素） + Blender（8 方向 sprite 渲染） | 见 `docs/协作/角色-美术.md` |
| 打包 | PK3 + 启动脚本 | demo 阶段不做安装器 |

## 7. 三周 solo 排期

### Week 1：技术验证（最重要）
- Day 1–2：装 UZDoom + Freedoom，跑通；装 UDB/SLADE。
- Day 3–4：生成中文字体子集，HUD 中文显示，测试断行。
- Day 5–7：一张测试图 + 自定义 HUD + 中文主菜单。

### Week 2：内容
- Day 8–10：地图白盒 + 2 敌人 + 2 武器。
- Day 11–12：2 个抉择门 + 结算页。
- Day 13–14：文案/UI 占位美术/音效占位。

### Week 3：打磨
- Day 15–17：3–5 人 playtest，修断行/难度/引导。
- Day 18–19：录 3 分钟演示视频 + 一页纸说明。
- Day 20–21：备份、打包、汇报材料。

> 如果 Week 1 的中文字体验证失败，立即停下来换方案（Godot/H5），不要硬撑。

## 8. 合规/审核清单

- 不使用 DOOM 名称/标志做宣传；对外叫“反诈战士”，注明引擎技术。
- 不使用 doom.wad；Freedoom 占位，最终替换原创。
- 无血腥；敌人为骗术具象化；避免“射杀真人”画面。
- 96110、国家反诈中心 APP 的文案按官方口径；不虚构案例细节。
- 不指责受害者；结算页加“被骗不是你的错，及时报警”。
- 发布前走单位内容审核；商用另议版号/GPL。

## 9. 风险

| 风险 | 等级 | 应对 |
|---|---|---|
| 中文字体/断行 | 高 | Week 1 必须验证，失败就换引擎 |
| 教学效果变成“换皮” | 高 | 抉择门即时反馈 + 结算复盘 + 用户试玩 |
| 美术工作量 | 中 | demo 用 Freedoom/色块占位，不画全套 sprite |
| 引擎版本分裂 | 中 | 锁定 UZDoom 或 GZDoom 一个版本 |
| 内容审核 | 中 | 提前用官方口径，避免真实机构/人物 |

# 音频设计

> 一句话定位：**"从诈骗现场捡回来的录音"**。
> 不追求电影级拟真，追求"这地方真的发生过"——劣质扩音器、机房风扇、对讲机、审讯室的回声。

---

## 1. 三层结构

| 层 | 出现频率 | 作用 | 本作对应 |
|---|---|---|---|
| 反馈层 | 每 0.2–0.5 秒 | 让操作"有重量"，必须抢在视觉之前 | 枪声、拾取、门禁应答、菜单 |
| 空间层 | 每 10–30 秒 | 交代"这是什么地方" | 门、警报、环境底噪 |
| 叙事层 | 每章 1–3 次 | 交代"这里发生了什么" | 敌人台词、Boss 进场 |

三条原则：

1. **反馈音必须在 30ms 内起声**，否则玩家会觉得"按了没反应"。
2. **叙事音只出现在玩家停下来的时候**，战斗中不抢反馈。
3. **同一逻辑事件只用一种音色**：证据是双音上行，门禁是蜂鸣，警报是三连降——玩家不看画面也能分辨。

## 3. 已接入部分的设计说明

### 3.1 为什么这样挂

| 事件 | 音效 | 为什么放这里 |
|---|---|---|
| 玩家碰到终端 | `fz/gate_open` | 玩家感知到"终端被激活"，比看见菜单更早 |
| 选对 | `fz/gate_close` | 语义是"放行/闸门关闭"，与 +10 防骗盾同帧 |
| 选错 | `fz/alarm` | 警报必须先于掉血，让 25 点伤害有"原因" |
| 菜单移动/确认/返回 | `menu/*` | 覆盖引擎内置名，地图内抉择菜单与主菜单同时生效 |

### 3.2 可调参数

- 单条音效的音量：`SNDINFO` 里加 `$volume <逻辑名> <0–1>`，不用改代码。
- 武器音量：`A_PlaySound("fz/pistol", CHAN_WEAPON, <volume>, ATTN_NONE)`。
- 敌人语音距离衰减：`ATTN_NORM`（默认），Boss 用 `ATTN_IDLE` 拉远。

## 4. 音乐 brief

三章 + 标题 + Boss，共 5 首。统一要求：**能无缝循环、不抢枪声、听 3 分钟不烦**。
曲目名与 `MAPINFO` 的章节标题保持一致。

| 曲目 | 用途 | 情绪 | BPM | 调式 | 配器要点 | 结构 |
|---|---|---|---|---|---|---|
| `title` | 标题/选章 | 悬置、待命 | 70 | D 小调 | 单音铺底 + 稀疏脉冲 + 磁带底噪 | 20–30s 循环 |
| `ch1` | 第一章 刷单深渊 | 冷、机械、重复 | 128 | A 小调 | 低音固定音型 + 金属敲击，像流水线；远处叫卖 | 8 小节前奏 + 32 小节主体循环 |
| `ch2` | 第二章 装备黑市 | 市集、油滑、试探 | 92 | E 小调 | 手鼓/铃 + 低音贝斯，中段留空 | 两段式，B 段加层 |
| `ch3` | 第三章 警服幻影 | 权威、压迫、伪善 | 110 | C 小调 | 军鼓进行 + 铜管动机 + 远处警笛 | 慢起，1 分钟后加层 |
| `boss` | 主席战 | 失控、倒计时 | 140 | F 小调 | 章节曲加速重编、失真 bass | 8 小节 loop，可叠加警报 |

技术规格（与 `docs/贴图与音乐方案.md` §2.4 / §5 一致）：

- OGG Vorbis，44.1kHz 立体声，质量 **q5**；
- 首尾样本对齐（无缝循环），整体响度 **−16 LUFS**，真峰值 ≤ **−1.5 dBFS**；
- 文件放 `game/music/ch1.ogg` 等，`MAPINFO` 写 `Music = "music/ch1.ogg"`；
- 游戏内音乐音量默认比音效低 6dB，保证枪声清晰。

验收标准：连续循环 3 遍听不出接缝；开一枪后音乐不"糊"；关掉音乐后场景仍成立。

### 4.1 落地记录（2026-11-23）

五首全部落地在 `game/music/`，`MAPINFO` 三章改指自己的文件，标题画面用
`gameinfo { titleMusic = "music/title.ogg" }`。`boss.ogg` 已生成，但三章里还没有
Boss 关，等 Boss 图做出来再在它的 `MAPINFO` 里写 `Music = "music/boss.ogg"`。

| 曲目 | 时长 | 前奏 / 循环点 | 循环体 | 实测响度 / 真峰值 |
|---|---|---|---|---|
| `title.ogg` | 27.4 s | 无前奏，整曲循环 | 27.4 s | −16.1 LUFS / −2.1 dBFS |
| `ch1.ogg` | 75.0 s | 15.0 s（第 8 小节） | 60.0 s | −16.0 LUFS / −2.0 dBFS |
| `ch2.ogg` | 104.4 s | 20.9 s（第 8 小节） | 83.5 s | −16.1 LUFS / −1.6 dBFS |
| `ch3.ogg` | 104.7 s | 34.9 s（第 16 小节） | 69.8 s | −16.1 LUFS / −1.7 dBFS |
| `boss.ogg` | 41.1 s | 13.7 s（第 8 小节） | 27.4 s | −16.1 LUFS / −1.5 dBFS |

- 循环点写在 OGG 的 Vorbis 注释里：`LOOP_START` / `LOOP_END`，单位是**采样**（不是时间）。
  引擎侧由 ZMusic（`music_libsndfile.cpp`）读取，纯数字按采样解析、带冒号按时间解析。
- 做法：本地音源渲染音符 → 叠一层很轻的程序化环境层（磁带底噪 / 机房嗡鸣 / 市集人声 / 远处警笛）
  → 把循环点之后的尾音折回循环点 → 接缝不干净时用 30 ms 等功率交叉淡化抹平
  → 归一化到 −16 LUFS、真峰值 ≤ −1.5 dBFS → libvorbis q5 封装。
- 制作链在 `D:\Project\音乐美术生成\music\`：`compose.py`（谱面）→ `calibrate.py`（逐轨电平标定）
  → `build_music.py`（渲染 / 循环 / 响度 / 封装）。乐谱是 JSON，改一首只需改音符重渲，
  不需要重新作曲；每首也留了分轨工程，可单独调增益。
- 中国元素是点缀，不是主体：编钟（标题 / 第一章 / Boss 警报）、琵琶（第二章市集）、
  唢呐（第三章最后 8 小节）。都是 GM 近似音色（编钟→Tinkle Bell、琵琶→Banjo、唢呐→Shenai）。

### 5.3 录音规范（交给配音者）

- 44.1kHz / 16-bit / **单声道** WAV；
- 近麦 10–15cm，加防喷罩，房间越干越好（衣柜、被褥都行）；
- 峰值不超过 −3 dBFS，底噪低于 −50 dBFS；
- 每条前后留 0.2 秒静音，不要自己加混响/压缩/降噪；
- 一条不过就整条重录，不要拼接。

### 5.4 后期与集成

1. 统一增益到 −16 LUFS，高通 80Hz，轻饱和（让声音"旧"一点）；
2. 按命名放进 `game/sounds/voice/`；
3. `SNDINFO` 登记：`$sound fz/voice/shill_sight sounds/voice/FZSHL_SIGHT.wav`；
4. Actor 里挂槽位：

```zs
class FZShill : ZombieMan replaces ZombieMan
{
    Default
    {
        SeeSound    "fz/voice/shill_sight";
        PainSound   "fz/voice/shill_pain";
        DeathSound  "fz/voice/shill_death";
    }
}
```

### 5.5 试音流程（先做一个人）

1. 找一位配音者，只录 Shill 的 3 条；
2. 接进 FZ01，实机走一段；
3. 确认声线、响度、后期方向；
4. 再铺开到其余 5 个角色；
5. 最后统一混音校准。

> 如果暂时找不到人：用 Windows 中文 TTS 生成同名的 3 条占位，先验证"人声进游戏"的整体效果，
> 真人到位后直接替换文件，代码与 SNDINFO 不用动。

## 6. 混音与优先级

| 层 | 目标响度 | 衰减 | 同时发声上限 |
|---|---|---|---|
| 武器 | −8 dBFS | `ATTN_NONE` | 3 |
| 敌人语音 | −10 dBFS | `ATTN_NORM` | 1 |
| 拾取/UI | −14 dBFS | `ATTN_NONE` | 2 |
| 环境/门 | −18 dBFS | `ATTN_NORM` | 2 |
| 音乐 | −18 dBFS | — | 1 |

规则：语音优先级最高（被打断就重播），警报其次，枪声可以互相覆盖。

# 反诈战士 · 剧情设定稿（v1.0，夜间开发版）

> 玩家身份：反诈特勤队见习探员，通过"净网装置"潜入诈骗集团的骗局网络空间，
> 将骗术具象化为数据妖魔并净化。三大案件 = 三章，难度与情感递进。

## 核心机制映射（Doom 原生）

| Doom 概念 | 反诈含义 |
|---|---|
| Health 100 | **警惕值**：被骗一次（错误抉择）扣警惕值；归零=深度被骗，行动失败 |
| Armor | **防骗盾**：吸收"话术攻击" |
| 弹药 | **举报能量**：武器弹药 |
| Key | **证据碎片**：集齐证据链才能开启最终审判门 |
| Switch | 举报开关（开门/净化节点） |
| Teleporter | 网络节点跃迁 |
| Boss | 每章幕后主谋 |

## 抉择门（每章 2 个，核心玩法）

接近后按使用键（E/空格）打开抉择菜单，选错立即惩罚并弹出知识点，选对奖励。

### 第一章《刷单深渊》案件简报
大学生小陈被拉进"闪电赚钱群"，动动手指日赚300。潜入其骗局空间净化。
- **门1**：群主发来"新手福利单"，完成 29 元任务立返 35 元。随后大单"垫付 299 可返 380"。
  - ❌ 垫付 299 → 扣警惕值 25，刷单托儿伏击。知识点：**凡是让你先垫资的刷单都是诈骗**。
  - ✅ 拒绝并举报 → 得证据碎片，奖励防骗盾。知识点：**刷单返利先给甜头后宰客，垫资即诈骗**。
- **门2**：客服称"系统卡单，需下载 XX 会议 APP 共享屏幕指导操作"。
  - ❌ 共享屏幕 → 扣警惕值 25，假客服伏击。知识点：**共享屏幕=把银行卡密码拱手送人**。
  - ✅ 挂断并拉黑 → 得证据碎片。知识点：**卡单、解冻、激活都是话术，拉黑举报一键解决**。
- **Boss**：群主"闪电哥"（Baron 原型）。掉落【主谋证据①】→ 开启出口。

### 第二章《装备黑市》案件简报
小陈的室友想买 3 折"内部价"皮肤，进了黑市交易群。
- **门1**：卖家称"平台要收手续费，加微信直接转，便宜 50"。
  - ❌ 微信直转 → 扣警惕值 25，盗号幽灵伏击。知识点：**脱离平台私下交易=放弃所有保障**。
  - ✅ 坚持官方平台 → 得证据碎片。知识点：**游戏交易认准官方渠道，担保交易才安全**。
- **门2**："限时 3 折皮肤"链接，需输入账号密码"验证资格"。
  - ❌ 输入密码 → 扣警惕值 25，盗号幽灵大举伏击。知识点：**低价皮肤是饵，账号密码交出去人就没了**。
  - ✅ 识破钓鱼链接 → 得证据碎片。知识点：**索要账号密码的"官方活动"都是钓鱼**。
- **Boss**：黑市商人"暗影"。掉落【主谋证据②】。

### 第三章《警服幻影》案件简报
"王警官"来电：小陈涉嫌洗钱，不配合就抓捕判刑，要求转账到"安全账户"自证清白。
- **门1**：对方要求把生活费全部转到"安全账户"配合"资金清查"。
  - ❌ 转入安全账户 → 扣警惕值 30，恐吓幻影伏击。知识点：**公检法不设安全账户，凡是要求转账的都是诈骗**。
  - ✅ 要求当面核实、拨打 96110 → 得证据碎片。知识点：**接到自称公检法的电话，直接挂断拨打 96110 核实**。
- **门2**：对方发来"协查 APP"，要求下载后开启屏幕共享"配合取证"，还说"案件保密，不许告诉任何人"。
  - ❌ 下载 APP → 扣警惕值 30。知识点：**真警察绝不会电话要求下载 APP 共享屏幕**。
  - ✅ 识破"保密"话术 → 得证据碎片。知识点：**"案件保密不许告诉家人"是怕你被劝醒，告诉家人就是反诈第一步**。
- **Boss**：幕后主谋"影子会长"（强化 Baron）。掉落【主谋证据③】→ 最终审判门开启。

## 结算/知识回收（每章末 intermission）

背景图为 PIL 生成的"案件卷宗"图（FZBKGRD1-3）。当前版本结算走引擎标准页（击杀/物品/时间），卷宗图作为后续自定义 finale 的预留素材；文案结构：识破点、错误代价、本章知识点（2-3 条）、96110 提示。

## 三章关卡结构（每张 8-12 分钟）

```
简报室(剧情墙+目标) → 走廊 → 竞技场1(托儿×n)
→ 抉择门1 → 证据收集区(迷宫小房+拾取)
→ 竞技场2(混合怪) → 抉择门2
→ 审判门(需3证据碎片) → Boss竞技场 → 开关出口
```

第三章额外加一段" Teleporter 网络跃迁"节点秀。
